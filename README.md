# STEPXHA Desk

Личное веб-приложение: база лидов и журнал сделок по металлам, нефти и валютным парам.

## Возможности
- Лиды: Telegram, оффер, партнёрка, источник, сумма, выплата клиенту, статус, срок холда, заметки.
- Сделки: инструмент, рынок, Long/Short, лоты, вход/выход, SL/TP, результат, комиссия, валюта и разбор.
- Добавление, редактирование, удаление, фильтры, поиск, графики и CSV.
- Резервная копия всех записей в JSON.
- Вход через ChatGPT; записи привязаны к пользователю на сервере. Синхронизация между устройствами после сохранения, обновления страницы или возврата во вкладку.

## Запуск
Node.js >=22.13, npm.

    npm ci
    npm run db:generate  # только после изменения схемы
    npm run build
    node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_absurd_prima.sql
    npm run dev

Открыть адрес, который выведет dev-сервер. Локальный вход создаёт тестового пользователя; в опубликованном приложении входом управляет Sites. Данные разработки и опубликованного сайта хранятся отдельно. Не публикуйте .wrangler, .env, node_modules или пользовательские выгрузки.

## Учёт
Лиды учитываются в RUB. Чистый результат считается только по статусу «Выплачен» и равен вознаграждению минус выплате клиенту. Кривая выплат строится по датам лидов, а не по датам фактического получения денег.

Результат сделки вводится из терминала: чистый P&L = результат до комиссии − комиссия и расходы. Если в терминале уже чистая сумма, укажите её и комиссию 0. Формула цены и лотов намеренно не используется: размеры контрактов зависят от брокера. Разные валюты показываются отдельно без конвертации. Открытые сделки исключены из реализованного результата и доли прибыльных. Дата сделки используется и для графика.

## Технологии и публикация
React 19, TypeScript, Vinext, Cloudflare Workers, D1 и Drizzle. Схема и миграции — в db/ и drizzle/. Настройки Sites — в .openai/hosting.json. Репозиторий содержит приложение, но не пользовательскую базу. GitHub Pages не поддерживает серверную часть этого приложения; для полноценной работы нужен хостинг Workers/Sites с D1 и входом.

## Дизайн
Собственный векторный знак STEPXHA: угловая S и восходящая молния. Uiverse и MotionSites использованы как ориентиры для интерактивных состояний и анимаций; код компонентов и графика написан для приложения, сторонние платные шаблоны не копировались. Уменьшение анимации учитывает prefers-reduced-motion.
