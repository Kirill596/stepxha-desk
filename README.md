# STEPXHA Desk

Сайт: https://kirill596.github.io/stepxha-desk/

Учёт лидов и журнал сделок. Сайт работает без регистрации и без отдельного сервера. Записи хранятся в localStorage этого браузера на этом устройстве. Между устройствами они не синхронизируются. Не очищайте данные сайта; регулярно выгружайте резервную копию через меню. Другие посетители не получают доступ к вашим локальным записям.

Корневые index.html, CSS, JS и SVG — готовая версия GitHub Pages. STEPXHA-pages-source.zip — её исходники. Архив STEPXHA-source.zip содержит прежнюю серверную версию.
