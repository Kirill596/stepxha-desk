# STEPXHA Desk

Сайт: https://kirill596.github.io/stepxha-desk/

Учёт лидов, журнал сделок и «Итоги дня» с AI-наставником. Данные хранятся в этом браузере, между устройствами не синхронизируются. Регулярно выгружайте резервную копию. Кнопка общей резервной копии включает дневник; в дневнике есть отдельная выгрузка. Ключ ИИ в выгрузки не включается.

## Бесплатный AI-наставник
Откройте «Итоги дня» → «Подключить ИИ». Войдите или зарегистрируйтесь в OpenRouter и подтвердите подключение. Используется OAuth PKCE S256 со сверкой state; ключ хранится только в sessionStorage текущей вкладки. Пароль не передаётся STEPXHA. Отозвать выданный ключ навсегда можно в OpenRouter. Кнопка «Отключить» удаляет ключ только из этой вкладки.

Запросы идут только в nvidia/nemotron-3.5-lightning:free, google/gemma-4-26b-a4b-it:free и google/gemma-4-31b-it:free, без платных fallback-моделей. Бесплатный лимит, модели и доступность зависят от OpenRouter. Если лимит исчерпан, появляется ошибка, дневник продолжает работать. Условия: https://openrouter.ai/docs/guides/routing/model-variants/free

Отправляется только выбранный отчёт и его переписка, после отметки согласия. Лиды и сделки не передаются модели. Ответы сохраняются с идентификатором модели. Наставник — ИИ, а не реальный предприниматель; его оценку нужно проверять. При правках отчёта старый разбор помечается как устаревший.

## Исходники
STEPXHA-pages-source.zip — исходники текущей браузерной версии: распаковать, npm install, npm run dev / npm run build (Node.js 22.13+). Готовые index.html, CSS, JS и SVG расположены в корне для GitHub Pages. STEPXHA-source.zip — архив прежней серверной версии.
